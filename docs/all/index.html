Every test we log

Everyone publishes the big benchmarks. Nobody logs the small ones, which are the ones that decide whether a model is usable: does it read the label, find the fact at 128k, emit a tool call that parses, fit the machine you own. 9 suites here, 0 community submissions so far, and every row says who ran it and on what.

Add yours. Copy the template, fill it in, open a pull request, or open an issue and it gets filed for you. A number with no machine named gets rejected by the validator, not by an opinion. Suites marked draft have no harness written yet, so the first submission defines the format.
