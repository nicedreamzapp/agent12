Write a single self-contained HTML file that renders a spinning 3D ball with WebGL2.

Requirements:

1. One file. No libraries, no CDN links, no imports, no external assets. Inline all CSS and JS.
2. A sphere built from triangles, roughly 2,000 of them, centered in view.
3. Shade it with a single directional light so you can see the curvature: bright where it faces the light, dark where it faces away.
4. It spins slowly on its own, animated with requestAnimationFrame.
5. Dragging the mouse spins it faster and changes the direction it is turning.
6. The canvas fills the window and the background is dark.

Output ONLY the contents of the HTML file. No explanation, no markdown fences.
